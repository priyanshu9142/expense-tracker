# Expense Tracker

A responsive expense tracker built with React and JavaScript to manage income and expenses.

🔗 **Live Demo:** https://expense-tracker-eight-virid-49.vercel.app/

🔗 **GitHub:** https://github.com/SHIVAMVATSA10/expense-tracker

## Features

- Add income and expense transactions
- Calculate total income, expenses, and balance
- Filter transactions by type
- Delete individual transactions
- Clear all transactions
- Persist transactions using LocalStorage
- INR currency formatting
- Form validation
- Responsive design for mobile and desktop

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- Vite
- LocalStorage
